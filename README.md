# 📚 AI Study Planner

An AI-powered Study Planner built using **Streamlit** and **Google Gemini AI** to help students create personalized study schedules, stay focused using the Pomodoro technique, track progress, generate quizzes, and improve productivity.

---

## 🚀 Problem Statement

Students often struggle with:

- Planning their studies efficiently
- Staying consistent
- Managing time
- Tracking progress
- Finding learning resources

AI Study Planner solves these problems by generating personalized study plans and productivity tools in one application.

---

# ⚙ Installation

Clone repository

```
git clone https://github.com/Aditiverma9988
```

Install packages

```
pip install -r requirements.txt
```

Run application

```
streamlit run app.py
```
